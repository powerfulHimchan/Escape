# 막차가 떠난 뒤

안드로이드용 아이소메트릭 도트 선택형 탈출 이야기입니다. 한 회차에서 50번 선택하고, 각 막에 시간 제한 선택이 한 번씩 나옵니다. 연결 장면은 선택 수에 포함되지 않습니다.

- 5막의 경로 수는 1, 2, 4, 8, 16개입니다.
- 엔딩 11개와 경로별 후일담이 있습니다. 엔딩에 실제로 영향을 준 선택을 다시 볼 수 있습니다.
- 소지품, 자동 저장, 이어하기, 막 시작부터 다시 보기, 엔딩 모아보기를 제공합니다.
- Android 6.0(API 23) 이상에서 실행합니다.

## 빌드

JDK 17, Gradle 8.11.1, Android SDK 35를 사용합니다.

```sh
python3 tools/validate_story.py
gradle :app:assembleDebug :app:lintDebug
```

APK는 GitHub Releases의 v0.1.1에서 받을 수 있습니다. 디버그 키로 서명한 직접 설치용 빌드입니다.
